# 📡 Signal dashboard

Live view over the compiled wiki. Generated by Dataview from note frontmatter — nothing here is hand-maintained, so it cannot go stale.

Up: [[+Home]] · Schema: [[AGENTS]]

> [!info] How to read `strength_basis`
> **`assessed`** — a human read the note and set `signal_strength`, `horizon` and `so_what`. Trust these.
> **`derived`** — computed from corroboration count, source independence and evidence accretion. The ranking is meaningful; the `so_what` is absent.
>
> `signal_strength` counts independent sources, not exciting words.

---

## 🔥 Act on these

Now or near-term, assessed, with a real so-what.

```dataview
TABLE WITHOUT ID
  file.link AS "Signal", pestle AS "Domain", signal_strength AS "Str",
  corroborations AS "Src", independent_sources AS "Indep", so_what AS "So what"
FROM "10 Notes"
WHERE type = "compiled" AND strength_basis = "assessed"
  AND (horizon = "now" OR horizon = "near")
SORT signal_strength DESC
```

## 🌅 Longer horizon

```dataview
TABLE WITHOUT ID
  file.link AS "Signal", pestle AS "Domain", signal_strength AS "Str", so_what AS "So what"
FROM "10 Notes"
WHERE type = "compiled" AND horizon = "far"
SORT signal_strength DESC
```

## 📊 Full ranking

Everything with signal data, strongest first.

```dataview
TABLE WITHOUT ID
  file.link AS "Signal", pestle AS "Domain", signal_strength AS "Str",
  strength_basis AS "Basis", corroborations AS "Src", independent_sources AS "Indep",
  horizon AS "Horizon", first_seen AS "First seen", last_evidence AS "Newest"
FROM "10 Notes"
WHERE type = "compiled"
SORT signal_strength DESC
LIMIT 60
```

---

## 🧭 By domain

```dataview
TABLE WITHOUT ID
  length(rows) AS "Signals",
  round(sum(rows.signal_strength) / length(rows), 1) AS "Mean strength",
  max(rows.signal_strength) AS "Strongest"
FROM "10 Notes"
WHERE type = "compiled"
GROUP BY pestle AS Domain
SORT max(rows.signal_strength) DESC
```

## 🕐 Freshest evidence

What has moved most recently. Once there is a few months of history behind this, it becomes the "what strengthened lately" view.

```dataview
TABLE WITHOUT ID
  file.link AS "Signal", last_evidence AS "Newest evidence",
  corroborations AS "Src", signal_strength AS "Str"
FROM "10 Notes"
WHERE type = "compiled" AND last_evidence
SORT last_evidence DESC
LIMIT 25
```

## 🐌 Gone quiet

Strong signals whose newest evidence is old. Either the story stopped, or the vault stopped watching.

```dataview
TABLE WITHOUT ID
  file.link AS "Signal", last_evidence AS "Newest evidence", signal_strength AS "Str", horizon AS "Horizon"
FROM "10 Notes"
WHERE type = "compiled" AND signal_strength > 5 AND last_evidence < date(today) - dur(3 months)
SORT last_evidence ASC
```

## ⚠️ Lint

### Needs a so-what

Ranked but unassessed. Working through these top-down is the highest-value manual task.

```dataview
TABLE WITHOUT ID file.link AS "Signal", pestle AS "Domain", signal_strength AS "Str", corroborations AS "Src"
FROM "10 Notes"
WHERE type = "compiled" AND so_what = "not yet assessed"
SORT signal_strength DESC
LIMIT 25
```

### Single-source claims

One independent source. Treat with caution regardless of strength.

```dataview
TABLE WITHOUT ID file.link AS "Signal", pestle AS "Domain", signal_strength AS "Str", confidence AS "Conf"
FROM "10 Notes"
WHERE type = "compiled" AND independent_sources <= 1
SORT signal_strength DESC
LIMIT 20
```

### Marked stale or contradicted

```dataview
LIST
FROM "10 Notes"
WHERE type = "compiled" AND stale = true
```

### Provenance unrecoverable

`first_seen` could not be established, so signal ageing does not work on these.

```dataview
TABLE WITHOUT ID file.link AS "Signal", pestle AS "Domain", first_seen_basis AS "Basis"
FROM "10 Notes"
WHERE type = "compiled" AND (first_seen = "unknown" OR first_seen_basis = "filed")
SORT signal_strength DESC
LIMIT 20
```

## 📥 Not yet in the picture

Concept notes with no signal data. They convert when new evidence touches them — see [[AGENTS]] §3. This is a backlog, not a to-do list.

```dataview
TABLE WITHOUT ID length(rows) AS "Concept notes"
FROM "10 Notes"
WHERE type != "compiled" AND type != "moc"
GROUP BY split(file.folder, "/")[1] AS Domain
SORT length(rows) DESC
```
