# Topic briefing (on demand)

Not a scheduled task — use it in a chat in your vault's Project whenever you need a rundown. Paste it, or save it as a Claude skill. Replace `TOPIC`.

---

Brief me on **TOPIC** using only my Obsidian vault.

1. Read `+Home.md` and the relevant category notes to route. Search `10 Notes/` for notes on TOPIC, including related terms.
2. Answer from the compiled notes, strongest evidence first. Drop to `05 Sources/` or the archive only if provenance is in question.
3. Structure:
   - **Bottom line** — two sentences.
   - **What the evidence says** — 4–6 bullets, each citing the note it came from as a `[[wikilink]]`, with its `signal_strength` and `independent_sources`.
   - **Where the notes disagree** — if they do. Don't smooth it over.
   - **Gaps** — what the vault doesn't know. Notes with one independent source or old `last_evidence` count as weak.
   - **Talking points** — three, if I'm likely to use this in a meeting.
4. Do not edit any notes. If you notice a problem, list it at the end.
5. If I tell you I used this, add nothing yourself — remind me to log it in `Admin/Attention log.md`.
