# About this vault

This vault is a **compiled wiki**: you feed it, Claude maintains it.

- **You:** drop things into `00 Inbox/` or `Clippings/`. Write your own thinking as concept notes. Log what you actually used in [[Attention log]].
- **Claude:** ingests captures into `10 Notes/`, keeps evidence counted and dated, flags contradictions, and never rewrites your words.
- **The rules:** [[AGENTS]]. That file is the only authority.
