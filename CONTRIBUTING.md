# Contributing

Thanks for trying it. The most useful contributions, in order:

1. **Problem reports.** [Open an issue](../../issues/new/choose) with what you expected, what happened, and the relevant lines from `_LINT.md` or `00 Inbox/_processing-log.md`. Remove anything private first.
2. **Lessons learned.** If an agent made a mess in a way `AGENTS.md` didn't prevent, describe it. The rules in this kit exist because each one fixed a real failure.
3. **Small fixes** to the docs or scripts, as pull requests.

Please keep `AGENTS.md` as the single source of truth: changes to note structure go there, not into templates or prompts.
